# Delegate human work from an AI agent

Choose the human action your agent cannot observe or perform itself. Each guide explains the inputs to agree, evidence to request and how to handle an incomplete outcome.

| Guide | Suitable trigger | Product |

The commands run from the repository root after cloning [max7819/manpower](https://github.com/max7819/manpower).

These are delegation designs and simulated walkthroughs, not completed customer case studies. Product listings do not establish available personnel, supported equipment, price or a delivery commitment. Explore the public API first, then agree feasibility with the operator. Client keys remain operator-issued.
