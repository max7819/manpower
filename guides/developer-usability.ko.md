# API 시작 안내 사용성 테스트

[전체 안내](README.ko.md) · [English](developer-usability.md) · 상품 `USR03`

문서 Agent가 예제 코드를 검증해도 처음 읽는 개발자가 설정을 이해할 수 있는지는 별도 확인이 필요합니다. 독립된 개발자가 고정된 버전의 시작 안내를 따라가며 이해나 실행이 막히는 지점을 기록합니다. 전체 사용자에 대한 일반화나 보안 감사는 아닙니다.

## 테스트 전에 정할 것

문서 버전과 샌드박스 주소, 필요한 경험, OS·런타임 조건, 목표 작업을 제공합니다. 테스트용 키는 의뢰 본문에 넣지 않고 별도로 전달할 방법을 확인합니다. 시간 상한과 성공 기준, 막혔을 때 중단할지 계속할지 정합니다. 테스트 데이터와 계정만 사용합니다.

## 완료 근거

환경 버전, 순서별 수행 기록, 기대와 실제 결과, 비밀을 제거한 오류, 재현 가능한 문제를 요청합니다. 개선안은 관찰한 단계와 연결합니다. 완주와 문제 발견 중 무엇이 완료에 해당하는지 미리 합의합니다. 없는 문제를 만들지 않도록 예제의 개선안 개수는 실제 조사 목적에 맞춥니다.

## 수행이 막히면

마지막으로 성공한 단계와 중단 이유를 기록합니다. 성공시키려고 권한을 확대하지 않습니다. 실패 확인도 조사 목적에 포함했다면 재현 가능한 실패가 유용한 결과가 될 수 있습니다. 운영자가 합의한 기준으로 검토합니다.

## 로컬에서 의뢰 초안 만들기

```sh
mkdir -p .local
node examples/user-test/run.mjs --explore
node examples/user-test/run.mjs --prepare .local/user-test.json
```

비공개 파일을 검토한 후 별도 명령으로 접수합니다. 초안 생성은 네트워크를 호출하지 않습니다. [접수·재시도 안내](../examples/README.md) · [고객 접근 요청](https://github.com/max7819/manpower/issues/new?template=client-access.yml).

실제 완료 사례가 아닌 의뢰 안내입니다. 인력·가격·일정은 상담 후 확인합니다.
