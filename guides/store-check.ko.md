# 매장 진열·가격 확인

[전체 안내](README.ko.md) · [English](store-check.md) · 상품 `RET01`

온라인 정보로 확인하기 어려운 특정 매장의 현재 진열 상태를 관찰하는 업무입니다. 진열대에 보이지 않는다는 사실과 재고가 없다는 판단은 다릅니다. 한 번의 방문으로 이후의 상태까지 보장할 수 없습니다.

## 방문 전에 정할 것

매장 주소, 방문 가능 시간, SKU와 포장 식별 정보를 제공합니다. 직원 확인 가능 여부, 촬영 규칙, 상품별 필요한 항목을 정합니다. 휴점·촬영 거절·상품 식별 실패 때의 처리도 합의합니다. 다른 매장이나 추가 방문은 범위를 다시 확인합니다.

## 완료 근거

관찰 시각과 시간대, 표시 가격과 통화, 보이는 수량 또는 진열 상태, 허용된 사진과 SKU의 연결을 요청합니다. 직접 본 내용과 직원 설명, 추정을 구분합니다. 읽을 수 없는 라벨이나 확인하지 못한 구역은 한계로 남깁니다. “합의한 진열대에서 보이지 않음”과 “재고 없음”은 서로 다른 결과입니다.

## 수행이 막히면

출입이나 촬영 허가가 거절되면 멈춥니다. 확인한 내용과 확인하지 못한 내용을 구분하고 부분 결과가 완료 기준에 맞는지 운영자가 검토합니다. 값을 추측하거나 임의로 방문 범위를 늘리지 않습니다.

## 로컬에서 의뢰 초안 만들기

```sh
mkdir -p .local
node examples/store-check/run.mjs --explore
node examples/store-check/run.mjs --prepare .local/store-check.json
```

비공개 파일을 검토한 후 별도 명령으로 접수합니다. 초안 생성은 네트워크를 호출하지 않습니다. [접수·재시도 안내](../examples/README.md) · [고객 접근 요청](https://github.com/max7819/manpower/issues/new?template=client-access.yml).

실제 완료 사례가 아닌 의뢰 안내입니다. 인력·가격·일정은 상담 후 확인합니다.
